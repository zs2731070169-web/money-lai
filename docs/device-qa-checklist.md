# 真机回归清单（任务 9.3，逐项走查留档）

执行方式：TestFlight 或 Xcode 直连真机，逐项勾选并记录机型/系统版本。

## A. 适配
- [ ] 异形屏（灵动岛机型）：计数器/元进程入口/翻盖直立均不被刘海遮挡
- [ ] 小屏（iPhone SE 系列）：构图完整、直立翻盖不遮金额里程表（自适应微后仰生效）
- [ ] 大屏（Pro Max）：钱包占比与留白协调
- [ ] 横竖屏：锁定竖屏，横屏不出现布局错乱

## B. 核心交互（v2.3 物理折叠）
- [ ] 上滑 28px 即时触发折叠（不等松手）；触发前翻盖不动（不跟手）
- [ ] 开启动画：快起 → 竖直附近最慢 → 重力荡过 → 轻微过冲 → 直立稳态（完整矩形）
- [ ] 全程翻盖不成一条线（侧对时呈皮革切边）
- [ ] 开盖和合盖经过约 50°～80° 的侧对区时，纹理与窄切边连续交接；正反面越过铰链时无瞬间大矩形、亮度突变或切边跳位
- [ ] 翻盖关闭、翻转中、直立时正反面四角连续圆滑，无条带台阶、横缝或明显卡顿
- [ ] 翻盖打开直立后顶部只有一道平滑外沿，无平行深色横纹；翻转中背面也无重复边框闪动
- [ ] 钱包开启时纸币在口沿上方自然露出，纸币与皮革交叠处无贴边错位；抓取瞬间纸币不跳位
- [ ] 关闭动画：重力下落 + 垫着陆轻拍声、无弹跳；触面末段现金不从盖下露出，翻盖不突然向下变长
- [ ] 折叠途中反向滑动可从当前进度转向
- [ ] 翻盖仅滑动开/合：轻点关闭态和开启态翻盖、钱包皮面及露出的纸币均无动作；纸币和余量区上拖过阈值可抽取
- [ ] 连抽：完成动画期间立刻再抓取无死区、不误关钱包

## C. 音频
- [ ] 静音拨片开启时游戏音效仍发声（AVAudioSession .playroom/.playback 生效，任务 5.5）
- [ ] 首次触摸后音频解锁；来电/切后台再回来，下次触摸音频恢复
- [ ] BGM 为钢琴质感（无电子琴感/无持续蜂鸣），音量低于操作音效
- [ ] 后台 BGM 淡出、回前台恢复
- [ ] 设置中关闭音效/BGM 即时生效，冷启动保持

## D. 触觉（任务 8.2）
- [ ] 翻盖掀起/纸币抽出/里程碑有轻触觉；系统触觉关闭后静默降级不报错

## E. 持久化
- [ ] 抽取进度（金额/张数）冷启动清零；图鉴/皮肤/成就/设置冷启动保留
- [ ] 飞行模式完整游玩（无网络请求）

## F. 元进程界面（任务 7.x）
- [ ] 图鉴：首抽录入、占位/完整两态
- [ ] 皮肤：解锁梯度展示（不显示累计数值）、切换即时生效、启用金框
- [ ] 成就：达成打点；设置开关三件套 + 隐私政策可达 + 版本号
- [ ] 轻提示：解锁/成就自动淡出、不阻断抽钞

## G. 发布前视觉审计（反廉价清单，game-visuals 规格）
- [ ] 全资产同色板/同光源/同线宽；无 emoji 图标、无彩虹渐变、无假广告素材
- [ ] 商店截图与实际玩法一致

## H. 备案与提交（任务 9.4）
- [ ] 工信部 App 备案号已取得并填入 ASC
