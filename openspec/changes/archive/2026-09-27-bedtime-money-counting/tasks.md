# Tasks：睡前数钱场景（bedtime-money-counting）

按 TDD 小步推进，每步先红后绿；`npm test` 为统一回归入口。日间既有测试不改全绿是全程验收线。

## 1. 剖面基础（纯函数层）

- [x] 1.1 提取 `FlapMotionProfile`（日间 = 现值 1050/950ms、5° 过冲；夜间 ≈1.4-1.8 倍、重阻尼、过冲 ≈0），`flap-state.ts` 剖面入参化；验证：既有日间单测不改全绿 + 新增夜间剖面单测（时长区间、无过冲、时间线特征）先红后绿
- [x] 1.2 `draw-judgment.ts` 跟手柔性延迟系数入剖面（夜间更粘）；验证：日间单测不变 + 夜间延迟增大的对比单测
- [x] 1.3 新建 `sleep-arc.ts` 纯函数 reducer（idle→dimming→dimmed、sealed 幂等、交互重置、触摸恢复、单调时钟推算入睡点、回前台补判）；验证：全状态转换单测覆盖（含锁屏冻结后恢复场景）
- [x] 1.4 夜间静默门控纯函数（呈现类/判定类 effect 分类，exhaustiveness `never` 断言）；验证：穷举全部现有 effect 类型的分类单测通过、新增类型漏分类导致编译失败

## 2. 夜间视觉

- [x] 2.1 `design-tokens.ts` 增加夜间基调变体与熄灭亮度系数接口；验证：快照测试更新镜像通过 + 大数字对比度 ≥3:1 断言（WCAG 验算含全部背景色板与纸基）
- [x] 2.2 渲染入口统一接入亮度系数乘算（各 painter 不改，`night-dim-painter` 全画面暖黑叠层、日间零绘制）；验证：画师级单调压暗/近黑/状态恢复单测（帧级夜间集成验证并入 5.4 模拟器实测）
- [x] 2.3 减弱动态效果与夜间剖面的叠加收敛（呼吸/漂移停用、过冲收敛在夜间同样生效）；验证：压暗与减弱动态无耦合单测

## 3. 睡眠音频

- [x] 3.1 `AUDIO_SYNTHESIS_PARAMETERS` 增加 sleep 编排块（BGM 速度/密度/顶棚 C4/音量、SFX 夜间增益、连抽上行禁用、熄灭淡出曲线）；验证：`tests/audio/audio-regression.test.ts` 内联镜像同步更新且快照通过
- [x] 3.2 engine 按会话切换睡眠编排 + 熄灭同步淡出/恢复淡入；验证：OfflineAudioContext 离线断言（夜间旋律发声音高 ≤C4、淡出无骤停、峰值 ≤0.9、无 NaN）
