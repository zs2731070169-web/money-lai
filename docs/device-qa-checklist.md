# 燃信真机与模拟器验收清单

每次执行记录日期、设备、系统版本、构建提交和结果。自动测试通过不能替代动态画面与声音验收。

## A. 首次启动与隐私

- [ ] 首次打开先显示本机存储摘要与隐私政策入口；同意前不出现主界面、不读手帐、不播放声音、不联网
- [ ] 同意后进入主界面；冷启动不重复询问，菜单仍可打开隐私政策
- [ ] 飞行模式可完成抽取、输入、燃烧、保存、浏览、清空；匿名统计静默跳过
- [ ] 菜单直接显示“本产品不提供医疗服务”和 12355
- [ ] 网络代理确认用户文字、图案、手帐、里程、外观和成就均不上传

## B. 三种屏幕尺寸与系统手势

- [ ] iPhone SE：信封、明信片、菜单、输入、统计句不裁切
- [ ] iPhone 17：菜单与燃烧定格位避开灵动岛，卡片底部避开 Home 指示条
- [ ] Pro Max：构图居中、留白协调，触点与画面一致
- [ ] 仅竖屏；横握时不产生横屏错位
- [ ] 抽取和甩出起点位于底部系统上滑区之上，回主屏手势不与玩法直接竞争

## C. 主循环与动画

- [ ] 静置页只有暖纸背景、信封、露出的明信片边缘与菜单，无常驻数字
- [ ] 明信片以 0.85 阻尼跟手，上缘领先，倾斜不超过 8°；抽出后图案完整
- [ ] 点按展开信纸后仍是同一张 `letter_paper.png`，无横线、输入框底色、额外边框或纸面蒙层
- [ ] 引导句和用户原文使用当前字体套餐，以低透明度正片叠底融入纸纹，无系统黑体回退、随机抖动、轮廓、模糊或投影
- [ ] 字体套餐页展示温柔手写、古典优雅、浪漫文艺三组预览；切换后立即更新选中态，重启仍保持选择，中英文混排不跳字体
- [ ] 书写态可输入或留白；取消输入不丢已有文字，键盘收起后布局恢复
- [ ] 向上位移超过屏高 15% 或速度超过 700px/s 时触发；未达阈值 300ms 回弹
- [ ] 2.7 秒火线从上缘匀速到下缘，使用外焰 `#D85A30`、内焰 `#BA7517`
- [ ] 燃烧中无矩形闪烁、纸缘锯齿、末段加速、全屏火焰、粒子、震动或触摸中断
- [ ] 烧过纸张半透明灰白并向上剥离；结束后无灰烬或其他具象残留
- [ ] 余光先停 0.2 秒，再在 0.6 秒内径向扩散至透明；不聚拢成形
- [ ] 手帐保存时菜单只亮一次 0.8 秒暖白微光，无弹窗、红点或音效
- [ ] 余光后静默 1.8 秒；第 1、3、5…次在有效计数时显示 0.6/1.8/0.6 秒统计句
- [ ] 统计句分两行，数字字号约为其余文字 1.6 倍；偶数次与网络失败均直接复位
- [ ] 主界面到手帐 0.6 秒渐暗，返回后暖纸色调不变

## D. 手帐与元进程

- [ ] 手帐按写入顺序展示图案和日期，默认不显示文字；点按或长按后才展开原文
- [ ] 空白记录详情只显示图案与日期；页角持续显示“这些东西只在这台设备上。”
- [ ] 明信片里程仅在菜单页出现，主界面无数字
- [ ] 独立图鉴固定 24 格；已收集显示图案，未收集只显示纸面轮廓
- [ ] 信封材质与明信片纸纹双槽可独立切换，未达里程阈值的外观不可启用
- [ ] 成就只包含取卡、燃烧、留白、图案收集和里程累计，无连续天数、排名、限时或医疗判定
- [ ] 同次解锁多个结果时只更新各页面，主循环无提示队列
- [ ] 清空前明确确认；取消不改变数据；确认后播放整页燃烧并只清除手帐和图鉴

## E. 导出与权限

- [ ] 导出长图只含图案、日期和本机说明，不含用户文字、里程、外观、成就或图鉴进度
- [ ] iOS 调起系统分享面板；成功、取消、失败后缓存临时 PNG 均已清理
- [ ] 取消或失败不改变手帐；失败只显示一次非模态提示
- [ ] `Info.plist` 无照片图库读写描述，系统设置中应用无照片权限项

## F. 音频与中断

- [ ] 拖纸沙沙声在点燃前 300ms 平滑结束；点燃声约 80ms、只触发一次
- [ ] 燃烧声集中在 200–800Hz，音量从 0.22 缓降到 0.10，呼吸周期约 0.8–1.2 秒，无爆裂脉冲
- [ ] 熄灭余响约 400ms；静默段与统计句无提示音
- [ ] 钢琴低于操作音效，燃烧期间连续，火灭后有约 2 秒自然长音；无持续“莎莎”底噪
- [ ] 真机静音拨片开启时仍可听见声音（AVAudioSession `.playback`）
- [ ] 切后台、来电或音频中断后淡出；回前台后的下一次触摸平滑恢复，无破音

## G. 性能与发布审计

- [ ] 连续燃烧 10 次保持流畅，火线固定采样，无逐帧增加的对象或绘制调用
- [ ] 500 条手帐快速滚动可交互；长图导出不因一次性超大画布崩溃
- [ ] 所有资产同色板、同光源、同线宽；无 emoji 图标、彩虹渐变或广告式素材
- [ ] 应用名、图标、启动页和商店截图均为燃信内容
- [ ] App Privacy 申报 Data Not Collected；无账号、广告、分析、第三方崩溃 SDK
- [ ] 计数 Worker 的 observability、Workers Logs、Logpush、事件采样和 Web Analytics 均关闭
