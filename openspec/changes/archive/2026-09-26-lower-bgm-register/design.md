# design：BGM 调域下移参数（实测反馈 v2.4）

| 参数 | 旧值 | 新值 | 依据 |
|---|---|---|---|
| 旋律音阶（MIDI） | 60~81（C5~A5），起点 72 | 48~69（C3~A4），起点 55（G3） | 舒缓钢琴参考音域；消除中高音驻留 |
| 琶音 octaveShift | 含两处 +1（最高至 C6） | 全部 0（低音根音 −1 保留） | 伴奏不过 C5 |
| 旋律琴槌瞬态 | 带通 2600Hz | 1800Hz | 高频敲击感收敛 |
| 第 3/4 分音增益 | 0.11 / 0.05 | 0.08 / 0.03 | 高频能量约降三成 |
| voice 低通 | 3800Hz | 3200Hz | 整体收暗 |

种子与确定性结构不变（同种子重放一致）；和弦进行、分解节奏型、稀疏行走、混响、音量比例（bgmBusGain 0.16）均不动。
