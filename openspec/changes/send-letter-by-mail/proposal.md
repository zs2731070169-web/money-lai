## Why

产品定位已从「只写给自己」转向「把心里话寄出去」：倾诉需要真实的收件人。收件人收到的不是一段文本，而是一只完整的信封——拆开、抽出信纸、听见莎莎声，才算读到这封信。寄送本身成为里程的意义来源：没寄出的信只是收好，寄出的信才走过距离。

## What Changes

- **寄送抉择弹层**：信纸在展示位上滑释放后弹出自绘弹层（暖纸样式、非系统对话框、不打断 BGM）。「存入自己的手帐」走现有链路但**不再累计里程**；「寄出这封信」进入寄送输入态。
- **寄送输入态**：仅需填写**收件人邮箱**（前缀输入 + 类型下拉：qq.com、163.com、126.com、gmail.com、outlook.com、icloud.com、自定义域），格式校验通过后可确认；发件人由系统邮件账户承担、发件城市自动取自档案；取消回弹层。
- **寄出动作**：先调用后端 `POST /dispatch` 写入寄送记录，随后经系统邮件客户端（`mailto:` 预填）发出拆信链接；链接内容为 URL fragment 的 URL-safe Base64（正文、日期、主题标记），拆信页本地解码。寄出的信**同时落入手帐并累计里程**。地址只记到**城市级**：按收/发邮箱域映射国家→代表城市，后端不存原始邮箱地址。
- **后端寄送记录（Worker + D1）**：只记**发件城市**与时间、用户 identifier——发件城市由 App 城市级定位一次、经随包城市坐标表反查写入档案（设置页可手动改，拒绝授权走手选），**不向收件人索取任何信息**：无收件城市、无距离计算、无 IP 猜测。身份与找回：**Apple ID 单一键（Sign in with Apple）+ 首启登录**——首次启动先完成 Apple 登录（系统面板两次点击，指纹/面容由设备硬件自定），随后进入主场景；所有数据从第一秒起归属该用户，书写与收好仪式全程不再出现登录。无匿名 ID、无双键、无合并、无打断。可选绑邮箱哈希仅作将来跨端预留。
- **里程语义反转**：里程从「收好次数」改为「**寄送里程**」——只有寄出的信累计；仅本地收好的信只入手帐、不进里程。里程页展示：累计寄出数、累计里程距离、最近寄送记录（发件地址、收件地址、单次距离）。成就与主题解锁门槛随之以寄出数/里程计。
- **数据架构：服务器长期存储，本地仅缓存，保证数据不丢失**：**全部**用户绑定数据——未寄出草稿、手帐记录、寄送记录、主题选择、字体套餐选择、成就与里程派生数据——均以服务端（D1）为长期存储与唯一事实源；本地（Capacitor Preferences）只作离线缓存与写穿队列。启动完成 Apple 登录后从服务端 hydrate，离线写本地队列、恢复网络静默补传；重装/换机后 Apple 登录即全量恢复，任何已留存数据 MUST NOT 因卸载、换机或离线而丢失。
- **隐私姿态修订**：放弃「用户内容仅存本机」红线——信件内容（含草稿）经用户绑定存入后端 D1，寄送经用户邮件客户端发出；**首次隐私同意门移除**；匿名计数协议不变。
- **失败降级**：后端不可用时寄送静默降级——邮件仍可发出，该封信在里程页标记「发送失败」，不计入累计（累计以后端记录为准）。
- **拆信页（新静态页 `viewer/`）**：合封展示 → 点按拆封 → 信纸自动抽出，手写字体原样排版，抽出带莎莎声；Base64 fragment 本地解码；坏链接降级空白信纸。

### Modified Capabilities

- `letter-burning`：上滑后插入抉择弹层与寄出路径（寄出=手帐+里程+后端记录+邮件）。
- `safety-privacy`：用户内容与寄送数据的边界改写（寄送出设备、后端存记录）。
- `meta-progression`：里程改为寄送里程，仅寄出累计；页面展示寄送记录与累计。

- **新增「设置」菜单项**：菜单为 里程 / 主题 / 字体 / 成就 / 手帐 / 设置 六项；主题与字体是内容装扮和将来的变现入口，保持顶层；设置页只收系统级全局项——所在城市、绑定邮箱、隐私政策及将来声音等开关；**不设「已购恢复」——已购内容随登录自动恢复**（服务端为准架构下权益与数据同键）。

- **IAP 预留**：将来内购以身份派生的稳定 UUID 作 StoreKit `appAccountToken`，权益记录同键存 D1——本期只定派生规则，不实现支付。

### Added Capabilities

- `letter-dispatch-viewer`：收件端拆信页。

## Impact

- `src/core/letter/` 新增 dispatch 抉择相位；编排层接弹层、后端调用与邮件发出。
- `src/adapters/` + 平台契约：寄送输入弹层（两组邮箱输入）与 `mailto:` 预填。
- `worker/`：新增 `POST /dispatch` 与 D1 存储；建表脚本以独立 `.sql` 文件放在 `scripts/sql/`（wrangler `migrations_dir` 指向该目录）；`GET` 聚合（总数/累计距离/记录列表）。
- `viewer/` 新静态入口；里程页改造；成就/主题门槛基准调整。
- 隐私规格、同意门文案随新定位复核（同意门是否保留另议）。
