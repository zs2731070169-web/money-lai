# 提案：心事升腾（bill-ascension）

## Why

产品情绪价值定位收敛为「有意义的解压」：不是单纯发泄，而是了却心事。纯留白的仪式（放飞无名数字）缺乏共鸣——用户心里没有对象就没有「了却」。采用被心理学验证的**写下烦恼再销毁**范式（表达性写作 + 仪式性放手）：写下=命名即抽离，亲手放飞=完成性收束，绝不留痕=无沉没成本。与睡眠场景不耦合，随时可做。

## What Changes

- **写下心事**：长按钱包口纸币堆 → 极简单行文本输入（≤30 字、无历史、**绝不落盘绝不上传**，随放飞销毁）
- **心事钞**：写下即化作一张字迹淡浮的特殊票面纸钞插入堆顶；可被抽出（抽起时字迹浮现），**计张数不计金额（面额 ¥0）**、不入图鉴、不参与确定性面额分配
- **亲手放飞**：按住里程表 → 数字在指尖凝成一沓纸币（微垂坠跟手）→ 拖上高处 → 松手=放飞（原地/拖回松手=纸沓落回取消）
- **升腾呈现**：纸钞自松手点升腾散开、漂远淡出；心事钞最后一个淡去（多留半拍）；声部=轻气流+五声钢琴琶音尾音；触觉=一次轻缓涟漪；夜间剖面自动软化但不静默（用户主动交互）
- **归零收束**：里程表滚动式下降归零（不跳变）→ 一拍静默 + 极轻文案「都过去了」；会话金额张数清零、可继续抽钞
- 元进程（`lifetimeDrawCount`/图鉴/皮肤/成就判定）全程无感；焚烧变体本期不做（未来「狠一点」模式保留）

## Capabilities

### New Capabilities

- `worry-release`: 心事写下与放飞的完整行为契约——心事输入（隐私边界）、心事钞（票面/抽出语义/¥0 面额例外）、放飞触发与取消、升腾呈现、归零收束

### Modified Capabilities

- `cash-drawing`: 「面额体系」增加心事钞例外条款（¥0 面额、确定性插入堆顶、不入图鉴、抽出计张不计额）
- `procedural-audio`: 新增「放飞声部」需求（轻气流 + 五声琶音、峰值/防爆约束、夜间软化、无声床）
- `platform-adaptation`: PlatformAdapter 新增文本输入出口（`presentTextInput`），维持平台无关内核纪律

## Impact

- `src/core/platform.ts` + `src/adapters/web.ts`：文本输入适配器接口与 Web 实现（DOM 输入仅在 adapter 层）
- `src/core/worry/`（新）：放飞状态机纯函数（凝沓/携带/松手/取消）
- `src/core/game.ts`：长按纸堆唤输入、堆顶插心事钞、里程表长按凝沓、放飞升腾、滚降归零接线
- `src/core/render/`：心事钞票面淡字、指尖纸沓跟手、升腾粒子（`flyingBills` 运动模型扩展）
- `src/core/audio/parameters.ts`：放飞声部参数快照（回归镜像同步）
- 测试：状态机单测、假适配器输入测试、离线音频断言、无头集成冒烟（写→抽→放飞→归零→再抽）
