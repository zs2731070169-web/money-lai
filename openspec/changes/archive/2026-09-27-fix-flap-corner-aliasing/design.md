# design：翻盖四角锯齿修复（离屏遮罩三段式）

## 根因链

```
paintFlapWithStrips（wallet-painter.ts）
  条带 i 目标矩形 = [±max(half_i, half_{i+1})] × [band_i 外扩 0.75px]（axis-aligned 矩形）
  源带 = 纹理全宽行带（中部行 100% 不透明）
    → 相邻条带矩形伸入角部弧线行，不透明全宽内容覆绘纹理抗锯齿透明圆角边距
    → 圆角被抹平：轮廓退化为条带矩形并集的硬台阶           ← 缺陷一（跨引擎）
  整体轮廓 clip()（投影多边形）
    → WebKit 的 canvas clip() 不做路径抗锯齿（Blink 会）
    → 外轮廓二值硬切，台阶零混色                            ← 缺陷二（iOS 独有）
```

取证方法：模拟器原生帧缓冲逐像素对比（翻盖角 0 过渡像素 vs 钱包体角 324 过渡像素）；
同引擎隔离页四象限对照（直绘光滑 / 纹理整体 drawImage 光滑 / 纹理+重合 clip 光滑 /
条带管线复刻零混色硬边）。

## 方案：三段式离屏渲染

对每个可见面（front/back），当面部纹理缓存可用时：

1. **内容段**：清空暂存面，按现有条带循环把纹理条带画进暂存面（**不再 clip**，
   条带矩形 ≤0.15 逻辑像素的侧向外溢留给遮罩段收敛）。
2. **遮罩段**：`globalCompositeOperation = 'destination-in'`，用**同一套**
   boundarySamples/源带映射再画一遍纹理条带——纹理自身 alpha（含四个圆角的
   抗锯齿边距）成为最终轮廓。逐像素与内容段对齐（同矩形、同源带），
   不透明带（α=1）不削减、圆角带按纹理 AA 削减，圆角以纹理分辨率光滑恢复；
   侧向外溢落在纹理透明边距内被自然裁掉。
3. **合成段**：`drawImage(暂存面, 翻盖包围盒)` 一次画回主画布（受主画布
   DPR 变换，边缘经双线性重采样，无二值边）。

为什么不用备选方案：
- 逐条带 clip：历史方案，相邻 clip 边缘分别 AA 产生透明横缝（fix-flap-strip-seams
  已修），回退即回归。
- 圆角化轮廓路径遮罩（一次 destination-in 填充）：需手工构造投影域内的椭圆角
  几何并与纹理弧线对齐，存在错位风险；遮罩段复用条带映射则对齐由构造保证。
- 只修 WebKit clip（如描边包边）：不解决缺陷一，圆角仍被覆绘抹平。

## 状态与资源

- 暂存面：翻盖面包围盒 × 渲染尺度，由 `Game` 持有、按尺寸重建复用，
  经 `PlatformAdapter.createOffscreenCanvas` 创建（内核不触平台 API，审计通过）。
- `createOffscreenCanvas` 返回 null（无头/能力缺失）→ 维持现有 `paintFlatFrontFace`
  平面降级，行为与今天一致（冒烟测试覆盖该路径）。
- 触面软压扁 / 掠射明度 / 盖影 / 皮革切边兜底均在主画布、合成之后绘制，不受影响。

## 风险与回退

- 绘制调用 ~101 → ~202/面（+100 遮罩条带 + 1 合成）：均为小四边形 GPU 位块传输，
  A 系芯片量级内；无头冒烟走降级路径不经过此管线。若实测掉帧，遮罩段条带数可
  降采样（透明度只在边缘有意义），但默认与内容段同粒度保对齐。
- destination-in 语义在目标含低 α 累积时的乘积次序无关（α 交集可交换），实现顺序不敏感。
- 回退：恢复旧 `paintFlapWithStrips` 单函数路径（git 单点还原），无数据/接口迁移。

## 测试策略（先红后绿）

- 单测（node 无头 + 假画布计数断言，沿仓库既有模式）：
  1. 遮罩段存在性：有纹理缓存时 `destination-in` 被调用、主画布收到一次合成 drawImage；
  2. clip 不再作为轮廓手段：主画布/暂存面调用序列中无 clip（内容段）；
  3. 降级不回归：无纹理缓存时仍走 `paintFlatFrontFace`。
- 回归：`npm test` 全量；`npx tsc --noEmit`（仅确认本变更文件零新增错误，
  meta-side-drawer 在途改动的既有错误不属本变更）。
- 视觉验收：`npm run launch` → 上滑开盖 → `simctl io screenshot` 原生分辨率放大
  四角：过渡像素 > 0、无整数像素台阶；对照钱包体角同帧同级光滑度。
