# design：BGM 混响卷积换 FDN

## 根因与决策

- 实测特征（与音符无关、起播即有、恒定）+ 合成层数值排除（残余伪声 ≤ -76dBFS）→ 实时欠载；恒定成本大头是 2.2s 立体声白噪 IR 的 `ConvolverNode`（每 128 样本块都做分区卷积，安静时也不停）。
- **整体替换而非缩短 IR**：缩到 1.2s 只省一半成本，分区卷积的常驻属性不变；FDN（Delay/Biquad/Gain 组合）每线每样本仅数次加减乘，成本数量级下降，且「零素材」规格不变。
- 用户裁决直接实施，不做静音/真机定位实验；若咔哒仍在，结论自动退化为「欠载源不在卷积」（真机验证模拟器音频栈），音频图降本仍成立。

## FDN 结构（createBgmReverbChain 内部）

```
wetSend(单声道) ──┬─→ [L1..L4 延迟线] ──tap──┬─→ leftSummer ─┐
                  │   每线: delay → LP(2.4k)  │              ├─→ merger → wetGain(0.4) → bgmBus
                  └─→ [R1..R4 延迟线] ──tap──┴─→ rightSummer ─┘
                       循环: LP → fbGain(0.72) → 回 delay 入
                       交叉: L 线 tap ×0.3 也进 rightSummer（对称）
dry(直通) ────────────────────────────────────────────────────→ bgmBus
```

- 延迟线时长互质、左右错开（L: 87/113/149/191ms，R: 97/127/157/197ms）避免周期梳妆染色。
- 循环低通 2400Hz：高频每圈多衰减 → 暗尾（兼修旧 IR 高低频同速衰减的颗粒感缺陷，贴合「偏暗收敛」音色规格）。
- 反馈 0.72 → -60dB 尾长最短线约 1.8s / 最长线约 4.1s，量级对齐旧 IR(2.2s)；wetGain 维持 0.4。
- Web Audio 循环合法性：环内 DelayNode ≥ 87ms ≫ 128 样本渲染量子。
- 节点总数 ~26 个、全静态（旧方案每块卷积 + 每音 18 节点不变）。

## 测试策略（先红后绿）

1. **红（契约）**：包一层 `createConvolver` 抛异常的上下文调用 `createBgmReverbChain` —— 现实现（ConvolverNode）必抛 → 红；FDN 后通过。锁死「欠载根因不得回归」。
2. **不变式（绿）**：单样本脉冲进 wetSend 离线渲染 1.2s——断言 [0.4, 1.0]s 窗口内有湿尾能量（混响存在性）、峰值 ≤ 0.9、无 NaN。旧实现同样通过（回归护栏，非判别）。
3. 既有引擎集成渲染（淡入起播：有声/防爆/无 NaN）继续兜底。

## 参数落库说明

混响参数（延迟表/反馈/循环低通/wet 增益）以内联常量留在 bgm-player.ts——现状（wet 0.4、2.2s）即内联；此刻把参数搬进 `AUDIO_SYNTHESIS_PARAMETERS` 会牵动参数快照镜像测试，而该测试正处于工作区在途变更的失同步状态，纠缠代价大于收益，本次不动。

## 回归验证入口

- `npm test` + `npx tsc --noEmit`（预期仅剩 3 个与音频混响无关的在途遗留失败）
- `npm run launch` 部署模拟器实听：咔哒消失 → 根因确认；仍存 → 转真机验证（结论退化为模拟器音频栈）
