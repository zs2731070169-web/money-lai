# 设计：翻盖侧对交接

当前 `paintWalletScene` 以 `rawSpread >= 0.3` 决定是否绘制整张纹理；低于阈值时 `paintLeatherEdgeIfNeeded` 立刻填充一块高 `0.3 * flapLength` 的圆角矩形，并按投影方向把矩形放在铰链上方或下方。纹理投影与矩形轮廓、颜色和位置都不同，越过阈值与投影符号翻转会造成单帧闪烁。

引入一个纯函数，将投影展布比映射为纹理可见度：展布 ≥0.18 时纹理完全可见，≤0.08 时仅留皮革厚度，在两者之间用连续缓动渐变。试绘时 0.08～0.30 的过宽渐变留下大块半透明表面，故收窄至真正接近侧对的角度。低可见度阶段还需把纹理的水平可见范围从透视自由边宽度连续收至钱包本体宽度，避免侧边留下半透明三角片。皮革切边使用 0.08 倍翻盖长度和钱包本体宽度，中心跟随自由边投影偏移的一半：展布恰为 0.08 时接住原投影范围，越过侧对角度时平滑穿过铰链；透明度为纹理可见度的补数。纹理及掠射明度按相同可见度淡出。正反面切换发生在纹理完全不可见的侧对区，避免色面硬切。保留 100 条带与投影圆角算法。

纯函数测试覆盖两个端点、单调性和跨正反面的对称性；画师集成测试检查硬切阈值两侧都有连续的表面与切边绘制，侧对时只有居中的窄切边。最后在 iPhone 模拟器逐角度查看开、合两向的中段帧。
