# App Store 审核备注与商店文案（任务 9.2）

## 审核备注（App Review Notes，提交时粘贴）

money-lai 是一款治愈系解压玩具：打开钱包、从中抽出无限供应的虚构纸币，观看金额累积。
全部功能离线可用，无账号、无内购、无广告、无任何数据收集。

功能清单（供 4.2「持续娱乐价值」评估）：
1. 核心玩法：手势触发钱包翻盖的物理折叠动画，沿钱包口滑动抽出纸币（跟手拖拽与点击两种方式均可），纸币面额分 5 档（虚构货币「lai 币」，确定性分配）
2. 钞票图鉴：每种面额首次抽出后录入图鉴（收集进度可视化）
3. 皮肤系统：9 款钱包/纸币皮肤，按累计抽取张数梯度解锁，可随时切换
4. 成就系统：累计型成就（首抽、百张、千张、万张、图鉴集齐）
5. 设置页：音效开关、背景音乐开关、触觉反馈开关、隐私政策入口、版本信息
6. 全程序化音频：开合皮革音、抽钞摩擦音、生成式钢琴背景音乐（无任何音频文件素材）
7. 本地存档：图鉴/皮肤/成就/设置保存在设备本地（抽取进度为会话级，冷启动重置——每次都是新钱包）

声明：应用内货币为虚构「lai 币」，与现实货币无关、不可购买或兑换；抽取结果确定、无随机博取机制；不含赌博元素。

## 商店文案

### App 名称
来钱 · 无限抽钱包 (money-lai)

### 副标题
治愈解压：打开钱包，纸币取之不尽

### 描述（首段）
轻轻上滑，钱包沿弧线缓缓翻开——纸币随手抽出，金额滚动上涨，钢琴声悠悠响起。没有目标、没有失败、没有广告，只有一只取之不尽的钱包陪你度过碎片时间。

### 关键词
解压,治愈,放松,数钱,钱包,ASMR,休闲,白噪音
