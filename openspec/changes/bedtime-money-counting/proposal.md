# 提案：睡前数钱场景（bedtime-money-counting）

## Why

核心循环（翻盖物理、跟手抽钞、程序化音频、触觉）已打磨到高完成度，但产品情绪价值缺场景落点：没有触发时机（没有任何时刻会让用户想起打开它）、动作无生活语义（抽这一下在生活里不代表什么）、攒下的只有收集向元进程（留存脚手架而非情绪身份）。将核心循环落到「睡前数钱」场景——睡不着数羊 → 睡不着数钱，「躺赚」的字面化——复用已高度完成的 ASMR 触感资产，为动作赋予意义框架与每日触发时机，并以「睡眠小账本」把攒下的东西变成被安抚过的证据。

## What Changes

- 新增**晚安模式**（sleep-mode）：夜间会话的入口（设置开关 + 夜间时间窗冷启动轻提示建议）、进入/退出语义，开关状态持久化
- **夜间交互剖面**：折叠更慢更粘（约为日间 1.4-1.8 倍时长、阻尼加重、过冲收敛）、触觉降为最轻档、全部日间功能保持可用
- **夜间反馈静默**：里程碑反馈与全部元进程提示（解锁/成就）在夜间全静默，判定照常发生仅呈现静默
- **夜间视觉基调**：既有暖粉彩色板体系内整体压暗，渐进熄灭（停止交互后渐暗至近黑）作为新允许的非用户触发运动
- **睡眠编排音频**：BGM 夜间变体（更慢、更稀疏、顶棚下调一个八度、音量进一步压低），熄灭时同步淡出至无声
- **会话封存 + 早安卡**：熄灭完成或主动退出时封存本夜记录（张数/金额/入睡点），次日呈现一次「昨晚数了 N 张 / ¥X 才睡着」早安卡
- **睡眠小账本**：逐夜记录与累计（总夜数/累计张数/累计金额），经元进程抽屉进入，持久化遵循既有元进程契约
- 本期**不做**（后置）：白天解压宣泄模式、熄灭后白噪音残留播放、跨设备同步

## Capabilities

### New Capabilities

- `sleep-mode`: 睡前数钱场景的行为契约——晚安模式入口与时间窗建议、夜间交互剖面、夜间反馈静默、夜间视觉基调、渐进熄灭与音频淡出、会话封存、早安卡与睡眠小账本

### Modified Capabilities

- `wallet-interaction`: 「真实物理的自主折叠（顶边铰链）」区分日间剖面（现状数值不变）与夜间剖面（更慢更粘、过冲收敛），几何约束与物理时间线特征保持
- `cash-drawing`: 「里程碑反馈」在晚安模式会话下全静默（无动效/音效/触觉/连抽音高上行），日间行为不变
- `procedural-audio`: 「生成式钢琴 BGM」增加晚安模式睡眠编排（更慢、更稀疏、顶棚下调一个八度、音量更低于日间 BGM，熄灭时同步淡出）
- `game-visuals`: 「动效原则」将非用户触发运动的白名单从两类扩为三类（新增晚安模式的渐进熄灭）
- `meta-progression`: 「元进程抽屉容器」菜单从四条目扩为五条目（新增「睡眠账本」入口）

## Impact

- `src/core/wallet/flap-state.ts`、`src/core/cash/draw-judgment.ts`：reducer 增加日间/夜间剖面参数（纯函数，单测先行）
- `src/core/game.ts`：编排夜间会话状态（进入/退出/熄灭计时/封存/早安卡路由），夜间静默效果门控
- `src/core/render/design-tokens.ts`：夜间低亮度令牌 + 熄灭亮度系数（快照测试更新）
- `src/core/audio/parameters.ts`：BGM 睡眠编排参数（音频回归快照测试同步镜像更新）
- `src/core/meta/`：睡眠账本持久化 schema 扩展（向后兼容，损坏静默重置沿用既有契约）
- 覆盖层：睡眠账本页（复用 overlay-layout 纯函数模式）、早安卡（轻提示队列扩展）
- 回归：reducer 剖面单测、离线音频渲染断言、无头集成冒烟、`npm test` / `npm run verify:specs` 全绿
