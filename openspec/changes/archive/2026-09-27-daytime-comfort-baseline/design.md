# design：日间基线舒缓化

## 关键决策

1. **值取自睡眠特性的夜间剖面**（用户认可的实际体验）：开合 1680/1520ms、跟手 0.75、
   BGM C4 顶棚/14s 和弦/2-7s 旋律间隔/0.095 总线、SFX ×0.6。物理剖面曲线形状、
   完成阈值 0.35、触发阈值 28px 等一律不动。
2. **main 无剖面机制，直接改基线常量**：`WALLET_FLAP_FOLD_*_DURATION_MS` 改值；
   抽钞增益以命名常量 `CASH_DRAW_DRAG_GAIN = 0.75` 乘入拖拽增量（不引入剖面入参）。
3. **SFX 总线**：main 引擎当前 SFX 语音直连 `busInputNode`（全局低通）。新增
   `sfxBus` 参数段与增益节点（0.6）串在 SFX 语音与全局低通之间；BGM 子总线结构不变
   （相对关系「BGM 显著低于操作音效」保持）。
4. **BGM 顶棚**：`bgm` 参数段新增 `melodyCeilingMidi: 60`（计划器本就支持可选顶棚入参，
   缺省 C5），`startBgm` 传入——不做整段移调，仍由顶棚逐音下折（计划器语义不变）。
5. **测试面**：flap 单测用常量相对断言自动适配；cash 单测比例断言按 0.75 修正期望；
   集成冒烟（tap-routing 等）开盖等待帧数按 1.6 倍放大（1050→1680ms ≈ 101 帧，
   75 帧不够）；音频快照镜像同步全部新值（调参必改快照纪律）。

## 测试策略（先红后绿）

- `audio-regression.test.ts` 快照镜像：bgm 四参 + melodyCeilingMidi + sfxBus.busGain。
- BGM 计划器级：旋律发声音高 ≤ C4（镜像分支上的顶棚断言写法）。
- `draw-judgment.test.ts`：0.5 行程 → 0.375 比例、2 行程 → 1（钳制）等按增益修正。
- `tap-routing.test.ts`：开盖等待帧 75 → 120（覆盖 1680ms + 余量）。
- 真机验收：模拟器冷启动听 BGM（低八度、慢、稀疏）、开合手感（慢而重）、抽钞粘度。

## 风险与边界

- 更慢的开合在「减弱动态效果」路径下时长如何收敛：既有规则只收敛动效不复述时长，
  相对常量断言保证行为一致。
- 帧预算不受影响（时长参数不增绘制成本）。
