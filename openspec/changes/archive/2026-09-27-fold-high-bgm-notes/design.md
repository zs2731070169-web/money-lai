# design：BGM 高音顶棚折下（实测反馈 v2.5）

| 参数 | v2.4 | v2.5 | 说明 |
|---|---|---|---|
| 旋律音阶 | C3~A4（48~69） | 恢复 C5~A5（60~81） | 中低段音高回到原版 |
| 高音顶棚 | 无 | C5（MIDI 72） | 发声超过顶棚才处理 |
| 越顶折下 | 无 | midi>72 → 发声 −12（76→64、79→67、81→69） | 游标按原音阶走，仅发声音高折叠，轮廓不变 |
| 琶音 octaveShift | 全 0 | 恢复两处 +1（最高 D5=74） | 柔和伴奏点缀，不参与旋律折下 |
| 音色 | 收暗（1.8k/分音/3.2k） | 保持 v2.4 | 未收到异议 |

实现要点：折下发生在 planNextEvents 生成旋律事件的发声频率处（frequencyHertz 按 folded MIDI 计算），行走状态（melodyScaleIndex/方向偏置/跳跃）继续用原音阶下标。
